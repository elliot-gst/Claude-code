Poudreuse
Freeride

Snowpark infini : carve sur le damé, envoie sur les kickers, glisse sur les rails. Chaque figure posée s'ajoute au combo, une chute le perd.

Stick gauche
Au sol : tourner. Haut = schuss (position de recherche), bas = freiner.
En l'air : gauche/droite = spin, haut = frontflip, bas = backflip. Spin + flip = Cork / Misty.
Saut
Maintenir pour fléchir, relâcher pour ollie. Relâche au bord du kicker pour plus d'air.
Grab
Maintenir GRAB en l'air. Stick neutre = Mute, droite = Safety, haut = Japan, bas = Tail.
Réception
Lâche le stick pour stopper la rotation : le skieur se cale sur le 180° suivant. Vise la pente de réception, pas la table.

Clavier : flèches / WASD, espace = saut, J K L I = grabs.
